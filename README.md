# dio-desafio-azure-openai-semantic-kernel
## Sobre o Projeto
Este repositório foi criado como parte do desafio da DIO para explorar a integração entre Azure OpenAI e o Semantic Kernel.

## O que foi explorado
- Como o Azure OpenAI fornece acesso aos modelos da OpenAI de forma corporativa.
- O conceito de **Semantic Kernel**, uma ferramenta que facilita a integração entre modelos de linguagem e funções tradicionais de programação.
- Realização de chamadas de API para o Azure OpenAI.
- Demonstração de como o Semantic Kernel pode ser usado para criar "skills" que combinam IA com lógica de aplicação.
